Plant Co. Gross Profit Performance Dashboard
Overview

This Power BI dashboard provides an interactive analysis of Plant Co.'s Gross Profit performance, allowing users to evaluate profitability trends across different dimensions such as country, product type, and time period. The dashboard compares current Year-to-Date (YTD) performance against Previous Year-to-Date (PYTD) results to identify areas of growth and decline.

Business Objective

The purpose of this dashboard is to provide stakeholders with a clear view of profitability performance, helping them:

Monitor financial performance over time.
Identify underperforming regions and products.
Analyze profitability drivers.
Support strategic decision-making through data-driven insights.
